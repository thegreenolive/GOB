# 04.00 Introduction

In previous chapters, the concepts of modeling and solving problems with instructions were introduced, but there was no formal way to create models oriented toward solving problems with code.

This chapter focuses on process modeling, the step in which a plan is created for implementing a logical, structured solution. There are three primary tools to that effect: **hierarchy charts**, **flowcharts**, and **pseudocode**. These tools operate on the principle of modularity, which allows for the subdivision of large issues into manageable units.&#x20;
