# 01.3 Hardware Architecture

The modern computer follows an architecture described by [John von Neumann in 1945](https://en.wikipedia.org/wiki/Von_Neumann_architecture). This model categorizes hardware into four primary elements: Input, Output, Processing, and Storage.

A computer communicates with the users through input and output devices. Displays, keyboards, speakers, microphones, printers, touch interfaces, and the mouse are common input/output devices. Processing and storage are carried out by the Central Processing Unit (CPU), the Main Memory, and the Auxiliary Storage Devices.

The CPU is the component of a computer that performs operations, consisting of the ALU (Arithmetic Logic Unit) and the Control Unit. The ALU contains the circuits necessary to execute arithmetic instructions and logical comparisons. The Control Unit manages instruction execution and coordinates the other components of the computer. The instructions are stored in the Main Memory. The core idea of a computer is sequentially executing instructions (arithmetic and logic) with the ALU under the direction of the Control Unit. Today’s CPUs are Multi-core, meaning they contain multiple processing units on a single chip, and operate at speeds measured in GHz (gigahertz), or billions of cycles per second.

The Main Memory is a temporary repository for data and instructions currently being processed. It is volatile, meaning its contents are lost when the power is turned off. Although there are several types of memory, the one used in this guide is the Random Access Memory (RAM). There are other [non-volatile memories](https://en.wikipedia.org/wiki/Computer_memory) that are used for specific computing purposes, but they will not be discussed in this guide.

The CPU must keep track of the instructions and results, just as a person using paper and pencil to calculate a long multiplication would, using registers. Registers are special-purpose, high-speed memories inside the CPU that hold only one piece of data at a time, such as the Accumulator (which stores the last result), the Program Counter (which holds the location of the next instruction), the Instruction Register (which holds the current instruction being executed), and [others](https://en.wikipedia.org/wiki/Processor_register).

For data and instructions that must be stored permanently, even when the computer is off, there is Auxiliary Storage. Older systems, [some still running](https://sfstandard.com/2023/02/02/sfs-market-street-subway-runs-on-reagan-era-floppy-disks/), used diskettes or floppy drives; modern systems use SSDs (Solid State Drives) for high-speed local storage and Cloud Storage for remote, network-based persistence.

#### The instruction cycle

The CPU runs incredibly small, step-by-step instructions at very high speeds. The process of executing a single command is divided into two cycles:

1. _The Instruction Cycle (Fetch/Decode_): The Control Unit locates the instruction in main memory and sends it to the CPU, where it is decoded into a format the machine understands.
2. _The Execution Cycle_: The ALU executes the instruction (e.g., addition or comparison) and stores the result in a register (e.g., the accumulator) until needed.

Because computers can only perform simple steps, a programmer must write precise procedures to tell the computer how to perform even mundane tasks, such as finding the largest number in a set. The idea of a machine that can solve problems by executing a set of instructions, one by one, while storing the results was developed by [Alan Turing](https://en.wikipedia.org/wiki/Alan_Turing) in 1936. Initially, the Turing Machine was a mathematical concept, but its application opened the possibilities of modern computing.
