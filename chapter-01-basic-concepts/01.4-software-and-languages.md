# 01.4 Software and Languages

A regular user usually does not directly interact with the hardware described in the last section. Layers of software around hardware need to be in place for a computer to be usable. A simple word processing program requires an operating system (OS) to interact with the hardware. The OS is a set of logical procedures that define how the computer interacts with its environment and manages resources, such as the File Manager and Scheduler. Common modern operating systems include Microsoft Windows, macOS, and Linux. Thanks to the OS, regular users can use application software, such as a word processor or a spreadsheet.

Application software is programmed using programming languages. Languages have evolved from hardware-oriented codes to human-friendly abstractions:

* Machine Level: The binary code (0s and 1s) that the hardware executes.
* Assembly Level: Uses symbolic representations (like "ADD" or "MOV") instead of binary. It is machine-specific and highly efficient.
* Procedural (Algorithm) Level: Oriented toward procedures, where the programmer specifies how the computer solves a problem step-by-step. Examples include BASIC, COBOL, and C.
* Object-Oriented Level: Incorporates data and the functions performed on that data into "objects". This promotes reusable code and is standard in modern development. Examples include Java, Python, Rust, and C++.

#### Translation: Compilers and Interpreters

Since computers only understand machine code, source code written by humans must be translated. The way a program is translated into machine language usually depends on the programming language used to write it. Some programming languages use a _Compiler_, which converts a full program to machine code and stores the result. Examples of languages that use compilers include C++, Rust, Java, and COBOL. Other languages use an _Interpreter_, which converts one instruction at a time to machine code.  Examples of languages that use interpreters include Python, JavaScript, and Ruby.

**Compilers**: Translate an entire program into machine code at once and store it in a file. This makes the program run faster but requires a separate translation step before execution.

**Interpreters**: Translate and execute the code one line at a time. This is often more flexible for development but generally results in slower execution speeds.
