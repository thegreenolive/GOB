# 01.0 Introduction

Even though computers are ubiquitous these days, the basic processes that allow them to work are not common knowledge. Therefore, before creating solutions using problem-solving and logical reasoning, one must understand the tool that will execute them: the computer. This chapter covers the fundamental concepts required for the remainder of the guide. While many students may possess general computer literacy, this introduction provides a framework to understand how hardware and software interact to process data.

It is critical to understand how a computer works at a fundamental level since the logic used in writing code is constrained by the capabilities and performance of the hardware. By the end of this chapter, you should be able to describe modern hardware components, the hierarchy of data, the basics of computer processing, and the different levels of programming languages.
