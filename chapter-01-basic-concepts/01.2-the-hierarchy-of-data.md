# 01.2 The Hierarchy of Data

In everyday situations, we group data to facilitate its manipulation. For example, the common way to refer to a basketball team is by its name rather than listing all its players. Manipulating information for all Denver Nuggets players under the name "Denver Nuggets" demonstrates the convenience of using hierarchy to handle data. To manage information efficiently in the digital realm, data is organized into a hierarchy ranging from the smallest electronic signal to massive, complex collections of facts.

The smallest unit of data that the computer can store is a bit. A bit is represented in a computer as a binary value (0 or 1) and stored in a bistable storage device. Computers produce output and process input using exclusively binary values, but bits are grouped in fixed numbers. A group of bits is called a word, and the most common group, a byte, is 8 bits. A word is used to represent complex information, such as text. [ASCII](https://en.wikipedia.org/wiki/ASCII) and [UTF-8](https://en.wikipedia.org/wiki/UTF-8) are among the most used coding systems.

Analog to the way that we use letters to create words, sentences, paragraphs, and whole books. Data is stored and processed in computers using bits and bytes as atomic elements for more complex forms of data. The data hierarchy and definitions for this guide are shown in Figure 01.2.
