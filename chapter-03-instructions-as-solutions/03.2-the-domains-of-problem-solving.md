# 03.2 The Domains of Problem Solving

The idea of analyzing a problem by exploring its origin, potential solutions, and possible implementations was introduced in Chapter 00. In this section, those ideas are expanded, focusing on the realm of problems that will be tackled using computer programs. To show how a problem should be analyzed, this section uses a simple example to illustrate how to identify issues in the problem domain (understanding the origin), solution domain (determining the tools), and implementation domain (the constraints of technology). Problem 1 is as follows.

{% hint style="warning" %}
Sum any five numbers.
{% endhint %}

<p align="center"><strong>Problem 1</strong></p>

Asking questions is the best way to elucidate the problem's conditions. The questions related to the problem domain concern the origin of the data to be manipulated and its formatting. The questions in the solution domain aim to help determine which tool to use. For the implementation of the solution, questions focus on users and the constraints of putting them in place. Some questions to ask about Problem 1 are shown below.

{% tabs %}
{% tab title="Problem Domain" %}
* Who or what will provide the numbers?
* What is the definition of a “number” for the problem (counting numbers, integers, decimal numbers, real numbers, complex numbers, etc.)?&#x20;
* Are there any constraints on the number size or precision?
* Are there always going to be five numbers?  If not, how many of these numbers might there be?
* Is there a specific formatting for the result?
* What will happen with the result (is it to be stored or shown)?
* Is it necessary to provide the original numbers as well as the results?
* Who or what will use the result?&#x20;
{% endtab %}

{% tab title="Solution Domain" %}
* Is there a specification for the kind of tools to use (pen and paper, calculator, computer)?
* If a computer is used, can a spreadsheet be used? Or some other existing program?
* Or, a new program must be created?
* How will the numbers be provided?&#x20;
* How will the results be communicated?
{% endtab %}

{% tab title="Implementation Domain" %}
* What is the skill level of the intended user of the solution?
* If, for example, a calculator is used, what kind? What capabilities does it have?  Is the intended user capable of manipulating it?&#x20;
* If a spreadsheet is used, which one?&#x20;
* If a program must be written, which language?
{% endtab %}
{% endtabs %}
