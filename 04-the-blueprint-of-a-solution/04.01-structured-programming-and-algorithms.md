# 04.01 Structured Programming and Algorithms

Before working on solution planning, it is convenient to define the nature of the programs described in this guide (from now on, the word _program_ will be used interchangeably with _solution_ and otherwise).&#x20;

A program is a list of instructions that a computer will carry out in the given order unless its own instructions indicate otherwise. The instructions in a program are executed from top to bottom, but certain sections of the solution are executed only under certain circumstances. For example, in Problem 1 of the previous chapter, after receiving the last number, the program must provide the sum of the numbers (rather than waiting for more numbers).

Programming Languages include mechanisms that allow following a sequence of execution (steps in the solution of Problem 1), selecting which instructions to execute (the decision to keep receiving numbers or not), and iterating (repeating similar instructions until getting all the numbers).  Sequence, selection, and iteration are features that facilitate **Structured Programming.** A programming language allows structured programming if it handles:

* _Sequence_: There are mechanisms to execute instructions/modules in the appropriate order to solve a problem
* _Selection_: There are mechanisms for deciding which instructions/modules execute, depending on the circumstances.
* _Iteration:_ There are mechanisms to repeat already executed instructions/modules if necessary.

The reader will notice the use of the term _module._ A module is a set of instructions that performs a specific task (for example, initializing variables).

***

An **algorithm** is a finite sequence of instructions, typically used to solve a class of specific problems or to perform a computation (see [Wikipedia](https://en.wikipedia.org/wiki/Algorithm)). Programs are usually built from modules that perform specific, diverse tasks that, taken together, solve a problem. Those tasks are sometimes well-defined (such as finding the highest number in a list), and there are known algorithms that solve them most efficiently. Additionally, problems specific to a given domain require the development of an algorithm to address them.

The methods described in the following sections assume the use of programming languages that support **Structured Programming** (most modern languages do), and that a program's implementation reflects an **Algorithm**.
